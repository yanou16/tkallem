# 3D coach avatar

`coach.glb` is the `brunette-t.glb` example avatar of TalkingHead by Mika Suominen
(https://github.com/met4citizen/TalkingHead, `avatars/`). The TalkingHead README states that its example avatar was
created at Ready Player Me and is "free to all developers for non-commercial use under the CC BY-NC 4.0 DEED"
(the `-t` variant is not listed separately). Tkallem uses it, credited here, for a non-commercial student project.

The 3D coach is off by default (students turn it on in voice mode). Replace this file with our own avatar (GLB with a
Mixamo rig, ARKit and Oculus viseme blend shapes) before any commercial use.
