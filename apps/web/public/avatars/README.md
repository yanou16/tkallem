# 3D coach avatar

`coach.glb` is the `brunette-t.glb` example avatar of TalkingHead by Mika Suominen
(https://github.com/met4citizen/TalkingHead, `avatars/`), used for the experimental 3D coach in voice mode.

The example avatars of that repository are provided for testing and are not covered by its MIT licence: check their
terms before any commercial use, and replace this file with our own avatar (GLB with Mixamo rig, ARKit and Oculus
viseme blend shapes) before production.
